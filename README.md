# StockPulse
StockPulse - Real-time stock market app for Android

## Datasheet clarification (Lütze NG-9001 DC 24-110V, Art.-Nr. 819001)

Based on the provided datasheet text, the converter is specified with **"galv. Trennung E/A: ja"** (galvanic isolation between input and output). For a DC/DC converter in this class, that indicates an isolated switched-mode topology and therefore a high-frequency transformer inside.

# Lütze NG-9001 (Art.-Nr. 819001): Transformer Clarification

From the provided datasheet text, the unit states **"galv. Trennung E/A: ja"** (galvanic isolation between input and output).

For a DC/DC converter in this class (DC 24–110 V input to 5.3 V output), galvanic isolation indicates an isolated switched converter topology, which in practice means a high-frequency transformer is used internally.

## Short answer

Yes — based on the provided datasheet information, this converter should contain an internal transformer.
